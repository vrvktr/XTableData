# Add People to Table

A responsive React + Vite application styled with Bootstrap 5.

## Requirements
- Node.js 20+ recommended
- npm

## Run locally

```bash
npm install
npm run dev
```

## Create a production build

```bash
npm run build
npm run preview
```

## Features
- Adds Place, Name, and Age to a table
- Validates required fields and age
- Clears the form after a successful add
- Clear button resets the current form
- Remove button deletes an individual row
- Responsive Bootstrap layout
